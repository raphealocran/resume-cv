# Resume CV — Interactive Online Resume

A clean, responsive single-page resume website for Rapheal Ocran, built with HTML and CSS.

## Features

- Single-page resume layout (contact, skills, awards, languages, profile, experience, education)
- Responsive two-column design for mobile and desktop
- Font Awesome icons

## Tech stack

- HTML5
- CSS3
- Font Awesome 4.4 (CDN)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Adding your photo

1. Create an `images/` folder in the project root.
2. Save your profile photo as `images/profile.jpeg`.
3. In `index.html`, uncomment the `<img>` tag in the top section.
